# REIST font assets

`reist-vga.psf` is generated from REIST's existing IBM-PC 8x16 kernel font by
`scripts/generate_psf2_font.py`.

`reist-unicode-bmp.psf` is generated by `scripts/generate_unifont_psf2.py`
from the vendored official GNU Unifont 16.0.04 HEX release. The exact source
archive is `source/unifont-16.0.04.hex.gz`, downloaded from:

https://unifoundry.com/pub/unifont/unifont-16.0.04/font-builds/unifont-16.0.04.hex.gz

Its pinned SHA-256 is
`f9c8c7802453f47be02677176aeac2342ee96d354fad7a26cedcce48e68e1d9f`.
GNU Unifont 16.0.04 is distributed here under the SIL Open Font License 1.1;
the complete license text, with normalized whitespace, is stored at
`source/OFL-1.1.txt`.

The REIST derivative preserves native 8x16 rows. For the current fixed desktop
cell, each 16x16 source row is reduced to eight pixels by OR-ing adjacent
columns. This intentionally prioritizes bounded complete BMP fallback over
typographic fidelity. It is not a shaping, bidirectional-layout or grapheme
engine.

`unicode.txt` is installed as `/usr/share/fonts/unicode.txt` as a visual
coverage sample. It uses real BMP text from several scripts and labels the
still-open combining, bidirectional, shaping and supplementary-plane behavior
explicitly.
